# useful_website

A collection of handy web tools and front-end demos.

## Overview

This repository is a set of static HTML/JavaScript pages. Each `.html` file typically represents a standalone mini-tool or demo that can be opened directly in a browser. It works well as learning material, classroom demos, or a quick-access toolbox.
